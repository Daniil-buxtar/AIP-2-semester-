What is CMS

CMS - "Content management system ( engine ) - a foundation for a website written by PHP programmers, with which you can manage the website (add content, change menu items, etc.) without knowing HTML and CSS.

However, in order to make a website using CMS you will need the services of a programmer, a designer, and a layout designer. And capital investments.

What types of cms are there?

There are different content management systems: for online stores, for blogs, for forums and so on.

Examples of cms

Examples of cms : Joomla, WordPress (for blogs), PhpBB (for forums).
